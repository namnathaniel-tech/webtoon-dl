Translation uses DeepL. Get a free key at deepl.com/pro-api (DeepL API Free, 500,000 characters a month), then paste it here. It's saved only on this Mac.
With a DeepL key, macOS text recognition reads each balloon and DeepL translates it (fast, free up to 500k characters a month; sound effects stay as they are). Without one, an AI model (Groq or Claude) reads and translates the pages using your translation guide. The English is lettered into the balloons; a script (original → English) and a series glossary are saved next to the files.

DeepL
Recommended. Free plan: 500,000 characters a month. Get a key at deepl.com/pro-api (choose “DeepL API Free”).
How to get a free DeepL key (2 minutes)
  1. Open deepl.com/pro-api and pick DeepL API Free, then Sign up for free.
  2. Create the account with your email. DeepL asks for a card to confirm you're a real person; the Free plan doesn't charge it.
  3. When you're in, open Account → API Keys (deepl.com/your-account/keys).
  4. Copy your key. A Free key ends in :fx.
  5. Paste it in the box below and click Save. When it says Saved, tick Translate to English before downloading.
Groq
Optional. Used only when there's no DeepL key. An AI model reads the pages and follows the translation guide; the free plan is slow (about a page a minute). Get a key at console.groq.com/keys.
Claude
Optional, for advanced users. Used only when there's no DeepL or Groq key. Set ANTHROPIC_API_KEY in the terminal before starting the app.

Keys are checked with the service when you save them and kept only on this Mac (~/Library/Application Support/webtoon-dl/, readable only by your account). They're never shown in full again or uploaded anywhere else.
